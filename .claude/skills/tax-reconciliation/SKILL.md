# Tax Reconciliation Skill - 电商涉税核对方法论

## 概述
这是一套面向中国电商卖家（淘宝主营 + 京东等多平台）的税务自查与对账技能。
当对话中提到"税务自查"、"涉税核对"、"平台对账"、"申报数据"等关键词时自动加载。

## 适用场景
- 一般纳税人，增值税13%/9%/6%
- 淘宝/天猫为主营平台，京东/小红书等多平台经营
- 按月申报增值税、按季预缴企业所得税

## 核心方法论：三步对账法

### 第一步：确定收入口径（最关键）

电商涉税收入有两种统计口径，必须先确认用哪种、差异多少：

| 口径 | 定义 | 用途 |
|------|------|------|
| **创建订单口径** | 当月1日00:00:00~末日23:59:59创建的订单金额 - 同期间退款完成金额 | 商家自用/ERP对账/目前申报依据 |
| **确认收货口径** | 当月内买家确认收货（交易成功）的订单金额 | 平台推送给税务局的涉税金额 |

**操作步骤：**
1. 分别按两种口径计算当月含税收入
2. 做价税分离：不含税收入 = 含税收入 / 1.13
3. 对比差异金额，分析差异来源：
   - A类差异：本月创建但未确收（在途订单）
   - B类差异：非本月创建但本月确收（上月在途）
   - C类差异：退款跨月（创建和退款完成不在同一个月）
4. 验证：全年累计两种口径应趋近一致

### 第二步：费用发票核对

平台收取的每一笔费用，按发票状态分类：

```
全部平台费用
├── 有专票（6%服务/9%运输）→ 进项税抵扣 → 减少增值税
├── 有普票 → 全额进费用 → 不能抵扣但有凭证
├── 无票 → 分类标记 → 汇算清缴可能纳税调增
└── 待取票 → 催平台开票 → 尽快取得发票
```

**淘宝/天猫开票规律：**
- 佣金（软件服务费）：每月出账后可在商家中心→账房→发票管理申请专票，税率6%
- 直通车/引力魔方/万相台：推广费，月结后申请专票，税率6%
- 技术服务费（年费）：年度结算，开专票，税率6%
- 淘宝客佣金：平台代扣，开专票，税率6%

**京东开票规律：**
- 佣金（平台使用费）：月结后可申请专票，税率6%
- 京东快车/京选：推广费，月结后可申请专票，税率6%
- 京东物流配送费：月结后可申请专票，税率9%（运输服务）

**小红书开票规律：**
- 佣金：月结后申请专票，税率6%
- 薯条/聚光推广费：月结后申请专票，税率6%

### 第三步：申报数据生成

```
增值税申报 = 销项税额 - 进项税额
├── 销项税额 = 不含税销售收入 × 13%（或对应税率）
│   └── 销售收入来源：第一步确定的口径金额
├── 进项税额 = 采购专票税额 + 平台费用专票税额
│   └── 平台费用进项：第二步中"有专票"部分的税额
└── 附加税 = 增值税 × 12%（城建7%+教育3%+地方教育2%）

企业所得税（季度预缴） = 利润总额 × 税率
├── 利润 = 收入 - 成本 - 费用
├── 注意：无票费用在汇算清缴时可能不能税前扣除
└── 小微优惠：≤100万实际5%，≤300万实际10%，>300万 25%
```

## Workflow Checklist（每月对账流程）

### 月度税务自查清单

- [ ] **1. 导出数据**
  - [ ] 淘宝后台导出当月已卖出的宝贝
  - [ ] 支付宝商家服务导出账务明细
  - [ ] 京东商家后台导出订单和结算单
  - [ ] ERP系统导出当月订单和退款数据

- [ ] **2. 收入口径核对**
  - [ ] 按创建订单口径计算当月收入
  - [ ] 按确收口径计算当月收入
  - [ ] 对比两种口径差异，记录差异原因
  - [ ] 与ERP数据交叉验证
  - [ ] 确认最终申报收入金额

- [ ] **3. 费用发票核对**
  - [ ] 登录各平台商家中心，下载/申请当月发票
  - [ ] 逐笔核对佣金发票（金额、税率）
  - [ ] 逐笔核对推广费发票
  - [ ] 标记无票费用并归类
  - [ ] 汇总可抵扣进项税额

- [ ] **4. 增值税计算**
  - [ ] 计算销项税额（申报收入 × 税率）
  - [ ] 汇总进项税额（采购专票 + 平台费用专票）
  - [ ] 计算应纳增值税
  - [ ] 计算附加税

- [ ] **5. 利润核算**
  - [ ] 汇总当月成本（采购成本 + 物流 + 包装）
  - [ ] 汇总当月费用（佣金 + 推广 + 人工 + 其他）
  - [ ] 区分有票费用和无票费用
  - [ ] 计算当月利润

- [ ] **6. 预警检查**
  - [ ] 毛利率是否低于预警线
  - [ ] 预算执行是否超标
  - [ ] 无票费用占比是否过高
  - [ ] 进项税额是否充足

## API 接口速查

| 功能 | 接口 | 说明 |
|------|------|------|
| 创建口径收入 | `GET /api/v1/revenue/by-calibration?calibration=order_creation` | 你们的口径 |
| 确收口径收入 | `GET /api/v1/revenue/by-calibration?calibration=confirmed_receipt` | 平台口径 |
| 双口径对比 | `GET /api/v1/revenue/compare` | 差异分析 |
| 全年累计对比 | `GET /api/v1/revenue/multi-month-compare` | 验证年度一致性 |
| 费用发票汇总 | `GET /api/v1/platform-fees/summary/{period}` | 有票/无票分组 |
| 可抵扣进项 | `GET /api/v1/platform-fees/deductible-input-tax/{period}` | 报税用 |
| 增值税计算 | `GET /api/v1/tax/vat/{period}` | 销项-进项 |
| 税务汇总 | `GET /api/v1/tax/summary/{period}` | 增值税+附加税 |
| 企业所得税 | `POST /api/v1/tax/corporate-income-tax` | 季度预缴 |
| 利润分析 | `GET /api/v1/analytics/profit/{period}` | 整体利润 |
| SKU利润 | `GET /api/v1/analytics/sku-profit/{period}` | 单品利润 |
| 平台ROI | `GET /api/v1/analytics/platform-roi/{period}` | 渠道ROI |
