# 淘宝/天猫平台对账参考

## 数据导出路径

### 订单数据
- **路径**: 千牛工作台 → 已卖出的宝贝 → 三个月内订单 → 批量导出
- **格式**: CSV/Excel
- **关键字段**: 订单编号、创建时间、付款时间、发货时间、确认收货时间、实付金额、退款金额、退款时间

### 账务数据
- **路径**: 支付宝商家服务 → 账务 → 账务明细 → 下载
- **备选**: 千牛 → 账房 → 账务中心
- **关键字段**: 交易流水号、入账时间、交易金额、服务费、实际到账金额

### 发票申请
- **路径**: 千牛 → 账房 → 发票管理 → 申请开票
- **开票周期**: 每月出账后（次月5号左右可申请上月发票）

## 收入口径差异分析

### 订单生命周期
```
买家下单(创建) → 买家付款 → 卖家发货 → 物流签收 → 确认收货(交易成功)
     ↓                                              ↓
  创建口径计入                                    确收口径计入
```

### 常见差异场景

**场景1：月末在途订单**
- 12月28日下单付款100元 → 1月5日确认收货
- 创建口径：计入12月收入
- 确收口径：计入1月收入
- 处理：差异=100元，标记为"在途订单"

**场景2：跨月退款**
- 12月10日下单付款200元 → 12月12日确认收货 → 1月3日退款成功
- 创建口径：12月收入200元，1月退款-200元
- 确收口径：12月收入200元，1月退款-200元（如果退款走原路返回）
- 注意：部分退款可能导致口径不一致

**场景3：天猫分期**
- 月末最后一天分3期付款订单
- 创建口径：全额计入当月
- 确收口径：按确收时间计入

## 对账要点

1. **账期注意**: 天猫的结算周期T+0或T+15，实际到账可能延迟
2. **优惠分摊**: 平台优惠券由平台承担，商家优惠券由商家承担，注意区分
3. **运费险**: 由保险公司结算，不影响商品收入
4. **多店铺**: 如有多个店铺，需分别导出后合并
5. **税率确认**: 确认适用税率（13%一般货物 / 9%农产品等）
